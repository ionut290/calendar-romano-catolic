# Calendar Romano-Catolic

Aplicație web/PWA în limba română pentru calendarul liturgic romano-catolic.

## Prima versiune
- pagina **Astăzi**
- calendar lunar navigabil
- sărbătoarea/sfântul zilei
- spații dedicate Evangheliei, meditației, vieții sfântului și rugăciunii
- PWA / suport offline de bază
- interfață responsive pentru telefon

## Următorii pași
Integrarea unei surse liturgice verificate, completarea calendarului anual și a conținutului în limba română.
